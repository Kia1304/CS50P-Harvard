## Week 0 main project: Tip Calculator

A Python script that prompts the user for a meal cost and a tip percentage, handles string cleaning (removing `$` and `%` signs), and calculates the correct amounts.

## Week 1 main project: 

### Key Learnings:
- arguments, datatypes and variables
- Function definitions and structuring code.
- Custom string parsing and float manipulation (`replace()`, `round()`).

### How to Run:
```bash
python tip.py
```
